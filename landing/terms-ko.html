이용약관

최종 갱신: 2026년 7월 30일 · 전자상거래법 §13 준수

1. 약관의 동의

StoreScope ("서비스") 에 접속하거나 이용함으로써 본 이용약관에 동의하는 것으로 간주됩니다. 동의하지 않으실 경우 서비스를 이용하지 마십시오.

2. 서비스 설명

StoreScope 는 공개된 Shopify 스토어프론트에서 파생된 상품 인텔리전스 데이터를 제공합니다. 서비스에는 API 접근, 트렌드 분석, 이커머스 리서치용 클러스터 데이터가 포함됩니다.

3. 서비스 이용

서비스는 합법적 목적으로만 이용하실 수 있습니다. 서면 허가 없이 데이터를 재판매, 재배포, 재라이센스 하지 않습니다. API 키는 양도 불가하며 공유해서는 안 됩니다.

4. 결제 및 구독

구독료는 월 단위로 청구됩니다. 모든 요금은 법률에서 요구하거나 환불 정책에 명시된 경우를 제외하고 환불 불가입니다. 가격 변경 시 30일 전 공지.

5. API 사용 제한

각 플랜에는 일일 요청 제한이 있습니다. 초과 시 속도 제한 또는 정지 가능. 서비스의 자동화된 남용이나 스크래핑은 금지됩니다.

6. 데이터 정확성

StoreScope 는 데이터를 "있는 그대로" 제공합니다. 정확성, 완결성, 시의성을 보장하지 않습니다. 사업 결정 전에 사용자가 독립적으로 데이터를 검증해야 합니다.

7. 지식재산권

StoreScope 가 생성한 집계 클러스터 데이터, 트렌드 인덱스, 파생 분석은 저희의 지식재산입니다. 원시 상품 데이터는 각 스토어 소유자의 재산으로 유지됩니다.

8. 해지

약관 위반, 미납, 남용 시 접근을 종료 또는 정지할 수 있습니다. 사용자는 언제든지 계정 대시보드에서 구독을 취소할 수 있습니다.

9. 책임의 한계

StoreScope 는 서비스 이용으로 인한 간접적, 부수적, 결과적 손해에 대해 책임지지 않습니다. 총 책임 한도는 직전 3개월 동안 지불한 요금을 초과하지 않습니다.

10. 관할 법

본 약관은 대한민국 법률의 적용을 받습니다. 분쟁은 서울중앙지방법원의 관할로 해결됩니다. 소비자 보호는 대한민국 전자상거래법 §13, §17, §21 및 소비자기본법에 따라 우선 적용됩니다.
